# 从 `7.2.1` 更新到 `7.3.0`

## 稀硫酸与稀盐酸
过去，将稀 H2SO4 与 HCl 蒸馏回可用酸时，H2SO4 使用 Circuit 1，而
HCl 使用 Circuit 2。现在两者统一为 Circuit 1。这会对现有基地造成非常轻微的破坏性影响。

## Chance Logic（概率逻辑）

- `first` ChanceLogic 已被弃用，因为其行为非常不可靠，并将在 8.0.0 中完全移除。
  我们建议改用 `xor`。

## KJS 错误
过去，KJS 配方中的空输入（如 `.inputItems('minecraft:gravl')`）会静默失败且不会添加物品。
我们让 inputItems 遵循回收逻辑，因此它现在要求 inputItems 必须有效且非 null。如果输入为 null 或无效，现在会抛出错误。
