# 从 `7.3.0` 更新到 `7.4.0`

## 新增 NBTPredicateIngredients
新增了一种 ingredient 类型，用于对 ItemStack NBT 数据进行更精细的模式匹配，参见 [NBT Predicate Ingredient](../Recipes/Ingredients/NBT-Predicate-Ingredients.md)。

## 平衡 sodium_bicarbonate_from_salt 配方
移除了从盐生产碳酸氢钠配方中的盐消耗口，参见 [上游 PR 4228: Balance chemical titanium recipe](https://github.com/GregTechCEu/GregTech-Modern/pull/4228)。

## 自定义 Recipe Logic 中的 ChanceLogic roll
_这只与拥有自定义机器和配方逻辑、并覆盖
`RecipeRunner.fillContentMatchList()` 或直接调用 `ChanceLogic.roll()` 的附属 mod 相关。_

`ChanceLogic.roll()` 的方法签名从：

`roll(List<Content> chancedEntries, ChanceBoostFunction boostFunction, int recipeTier, int chanceTier, Object2IntMap<?> cache, int times)`

改为：

`roll(RecipeCapability<?> cap, List<Content> chancedEntries, ChanceBoostFunction boostFunction, int recipeTier, int chanceTier, Object2IntMap<?> cache, int times)`

（chance roll 函数现在还需要传入当前正在处理的 RecipeCapability。）
