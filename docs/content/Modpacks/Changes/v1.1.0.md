# 从 `1.0.x` 更新到 `1.1.0`


## 电路物品标签

电路的物品标签已从 `#forge:circuits/<tier>` 改为 `#gtceu:circuits/<tier>`。
你需要相应更新所有相关配方。


## 配方 ID 变更

部分 recipe IDs 已发生变更。如果你按 ID 移除或修改配方，请检查这些 ID 是否仍然有效。


## 矿石岩石类型

由于矿石渲染方式发生变化，矿石岩石类型现在还需要提供基础模型位置：

```js
e.create('my_ore', 'ore')
    .baseModelLocation('some_other_mod:block/my_block')
    //...
```
