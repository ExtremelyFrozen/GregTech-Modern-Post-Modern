# 从 `7.2.0` 更新到 `7.2.1`

## AdjacentFluid() 与 AdjacentBlock()

为了方便 KJS 使用，我们为以下方法添加了重载：

- `adjacentFluid(ResourceLocation... tagNames)` -> `adjacentFluidTag(ResourceLocation... tagNames)`

以及

- `adjacentFluid(Fluid... fluids)` -> `adjacentFluids(Fluid... fluids)`

这样旧的 `AdjacentFluid(...)` 方法仍然存在，同时也提供了明确的 KubeJS 调用方式，避免模糊的 cast 或方法选择。

这些变化同样适用于 `.adjacentBlock()`。
