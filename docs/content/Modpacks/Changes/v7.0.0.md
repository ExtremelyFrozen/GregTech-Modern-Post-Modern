# 从 `1.6.4` 更新到 `7.0.0`

## 自定义 UI

在自定义 `.rtui` 文件中，你需要重命名以下引用：

  - `phantom_fluid_slot` -> `gtm_phantom_fluid_slot`
  - `phantom_item_slot` -> `gtm_phantom_item_slot`
  - `item_slot` -> `gtm_item_slot`
  - `fluid_slot` -> `gtm_fluid_slot`
  - `container` -> `gtm_container`

这可以用任意 NBT 编辑器完成，例如 [webNBT](https://irath96.github.io/webNBT/)。

## 模型

我们已经完全重做渲染系统，使其基于 model 而不是 renderer。

过去会这样写：
```javascript
        .workableCasingRenderer(
            "gtceu:block/casings/solid/machine_casing_robust_tungstensteel",
            "gtceu:block/multiblock/primitive_blast_furnace", false
        );
```

现在应改用：

```javascript
        .workableCasingModel(
            "gtceu:block/casings/solid/machine_casing_robust_tungstensteel",
            "gtceu:block/multiblock/primitive_blast_furnace"
        );
```
注意：第三个参数已被移除，不应再使用。


过去会这样写：
```javascript
        .workableTieredHullRenderer("gtceu:block/machines/reconstructor")
```

现在应这样写：
```javascript
        .workableTieredHullModel("gtceu:block/machines/reconstructor")
```

如需查找更新后的模型方法列表，单方块请查看 [MachineBuilder.java](https://github.com/ExtremelyFrozen/GregTech-Post-Modern/blob/1.21/src/main/java/com/gregtechceu/gtceu/api/registry/registrate/MachineBuilder.java)，多方块请查看 [MultiblockMachineBuilder.java](https://github.com/ExtremelyFrozen/GregTech-Post-Modern/blob/1.21/src/main/java/com/gregtechceu/gtceu/api/registry/registrate/MultiblockMachineBuilder.java)。大多数方法名称保持相近，只是将 `renderer` 替换为 `model`。
